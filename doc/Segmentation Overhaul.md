Let us rethink how SF works.

1. Select a file in DN.
2. Create a new session in DN.
3. Be sure the file selected in 1. is propagated to the SF node.
4. Open SF. If all is well, then the correct image appears. If the wrong image appears, then close SF, find the session in storage and delete it. Try again.
5. Once one has the correct image, click to detect WBs. When detection ends,
	a.  Deselect raw and current in Display Layers.  
	b. The masks show.  
	c.  Box select any orphaned WBs.
	d. Box select any other objects for permanent removal. A caption template is in the text area. 
	e. Scrub
 6. After scrubbing,   Display Layers/masks shows WB as they were and /current shows sans WBs.
7. Save. Q: What exactly is saved? Is the captioned saved? Can we select more objects select then save again. 
8. We select objects that we want to caption.  These are often objects that obscure other objects that we also want to caption.  Therefore we go through a process of selecting then captioning then scrubbing until we get to bottom of the stack.
